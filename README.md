> ✨ _"La vida es más alegre cuando vives para servir."_ ✨

Soy un líder de operaciones y tecnología con experiencia como **Ex-Director de Operaciones (COO)**, especializado en aplicar **Ciencia de Datos e Inteligencia Artificial** para resolver problemas de negocio complejos. Mi enfoque es simple: cerrar la brecha entre la estrategia y la ejecución técnica.

Traduzco los objetivos de negocio en hojas de ruta de productos de datos, lidero equipos multidisciplinarios (IA, Data Science, Backend) y gestiono el ciclo de vida completo de los proyectos, desde la arquitectura de datos hasta el despliegue de modelos de Machine Learning. Mi pasión es crear ecosistemas donde la excelencia técnica y un liderazgo centrado en las personas convergen para generar un impacto medible.

### 🚀 Proyectos Destacados (Portfolio)

Aquí es donde la estrategia se convierte en código. Estos proyectos demuestran mi capacidad para abordar problemas de negocio a través de soluciones de datos de extremo a extremo.

| Proyecto | Descripción Breve | Tecnologías Clave |
| :--- | :--- | :--- |
| 💼 **[The Leader's Dashboard: Predicting Burnout Risk](https://github.com/B-GUST/leader-dashboard)** | Un dashboard interactivo que utiliza un modelo de ML para predecir el riesgo de burnout y el "teatro de la productividad" basándose en métricas de gestión de proyectos. | `Python`, `Scikit-learn`, `Pandas`, `Plotly`, `Streamlit` |
| 🚚 **[Motor de Optimización de Rutas Logísticas](https://github.com/B-GUST/route-optimizer)** | Implementación de algoritmos para resolver el Problema del Vendedor Viajero (TSP), optimizando rutas de entrega para reducir costos y tiempos. | `Python`, `NetworkX`, `Folium`, `haversine` |
| 💬 **[Analizador de Feedback con NLP](https://github.com/B-GUST/feedback-analyzer)** | Una API que clasifica el feedback de los empleados para medir la seguridad psicológica, utilizando análisis de sentimiento y modelado de tópicos. | `Python`, `FastAPI`, `Transformers` |
